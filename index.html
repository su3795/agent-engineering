🤖 Agent 协作过程

🧠 推理与决策链（ReAct · Plan-and-Execute · Reflection）

每个 Agent 在产出结论前必须展示推理链，含证据来源与置信度。这是防幻觉与漏答的第一道防线。

🧪 评测与验收（Evaluation Gate）

没有评测体系的 Agent 无法证明「改了没有变差」。每次运行都要过三道关：独立测试套件 → 黄金集回归 → LLM-as-a-Judge 评审。

🛡️ 可靠性护栏（8 层防御）

护栏分三层：输入过滤 → 运行时控制（沙箱 / 最小权限 / 预算）→ 输出校验（Schema / 证据 / 拒答）。

📜 审计与回放（Audit Trail · 不可抵赖）

每一次工具调用、模型选择、门禁决策均留痕，包含决策原因。事后可复盘「为什么 AI 这么答」，并回放到任一历史状态。
